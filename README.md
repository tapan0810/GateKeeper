# GateKeeper

An intelligent API traffic management platform built with ASP.NET Core, Angular, PostgreSQL, Redis, and RabbitMQ.

## Technology Stack

- ASP.NET Core 10
- C#
- PostgreSQL
- Redis
- RabbitMQ
- Angular
- Docker

## Architecture

The solution is organized into:

- GateKeeper.API – API and gateway application
- GateKeeper.Core – Domain models and business abstractions
- GateKeeper.Infrastructure – External integrations and persistence
- GateKeeper.Worker – Background event processing

## Project Status

Initial solution structure created. Feature implementation is in progress.
